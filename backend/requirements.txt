# Pinned to versions installed during Phase 4 (2026-06-05).

# IMPORTANT INSTALL ORDER for new setups:
#
#   1. Create venv:
#        python -m venv .venv
#        .\.venv\Scripts\activate
#
#   2. Install PyTorch FIRST with CUDA 12.6 wheels:
#        pip install torch==2.8.0 torchaudio==2.8.0 torchvision==0.23.0 \
#                    --index-url https://download.pytorch.org/whl/cu126
#
#   3. Then install everything else:
#        pip install -r requirements.txt
#
# WHY THIS ORDER: whisperx hard-pins torch~=2.8.0 in its install spec. If
# you install whisperx BEFORE torch, pip will pull plain CPU torch from PyPI
# and silently overwrite any GPU build you already had. Installing torch
# first with the explicit CUDA wheel makes whisperx's resolver see "already
# satisfied" and skip the swap.
